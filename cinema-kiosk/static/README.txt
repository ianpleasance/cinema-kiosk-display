Put your own images here (jpg, png, webp, gif, bmp) and the display will show them
along with the film slides: house rules, offers, "coming soon", sponsors and so on.

- Any size or shape: images are scaled to fit the screen with black edges.
  1920x1080 fills the screen exactly.
- They are shown in file name order, so name them 01_..., 02_... to control the order.
- Where they appear among the film slides is set by STATIC_POSITION in ../.env
  (after / before / spread).
- No restart needed: the folder is checked at every slide change.
- Other file types (like this one) are ignored.
